# V1 Non-Goals

Strong non-goals are necessary to prevent a language project from becoming an
unfinishable collection of fashionable features.

V1 will not attempt to provide:

1. source compatibility with C++ templates, classes, headers, or preprocessors
2. a production-grade optimizing backend written from scratch
3. every GUI platform framework
4. a full game engine
5. kernel development as the first workload
6. hard real-time guarantees
7. distributed computing primitives in the language core
8. a borrow checker copied directly from Rust without usability validation
9. mandatory garbage collection
10. unrestricted macros or compile-time code execution
11. multiple inheritance
12. implicit nulls or truthiness
13. unchecked exceptions for expected failures
14. package install scripts with arbitrary machine access
15. separate competing official formatters or build systems
16. a stable C++ ABI
17. automatic source translation from every existing language
18. immediate self-hosting
19. support for every CPU and operating system in the first release
20. syntax features whose only justification is novelty

A non-goal may become a future goal only when it maps to a validated developer
pain and does not compromise the constitution.
