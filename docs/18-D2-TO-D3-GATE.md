# D2 to D3 Gate

D3 may begin only when:

1. the cumulative verifier prints the D2 golden-build marker
2. GitHub Actions is green
3. the D2 report counts match the manual guide
4. memory decisions are manually reviewed
5. the architecture syntax tour is coherent
6. the user reports `GG D2 Passed`

D3 implementation must follow the locked architecture. Any discovered conflict is
resolved through a decision record rather than silently changing semantics.
