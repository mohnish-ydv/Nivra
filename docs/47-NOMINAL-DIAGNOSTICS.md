# D7 Nominal Diagnostics

| Code | Meaning |
|---|---|
| NOM001 | Unknown field, method, or variant |
| NOM002 | Member access through unsupported or optional type |
| NOM003 | Required constructor field missing |
| NOM004 | Unknown constructor field |
| NOM005 | Duplicate constructor field |
| NOM006 | Constructor field type mismatch |
| NOM007 | Enum variant payload mismatch |
| NOM008 | Mutation requires a mutable receiver |
| NOM009 | Unknown nominal construction target |
| NOM010 | Enum used with record construction syntax |

All diagnostics contain a source range and an actionable next step.
